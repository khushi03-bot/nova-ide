## ⚡ About Nova IDE

**Nova IDE** is an open-source, beautifully designed Python editor tailored for students, developers, and researchers. It ditches the bloat of heavy IDEs while keeping the absolute essentials: a powerful step debugger, live variable inspection, a built-in terminal, and gorgeous themes. 

Developed as a modern alternative to IDLE, Nova IDE makes coding in Python incredibly simple and visually stunning.

## ✨ Features

- **🎨 Beautiful UI & Themes:** Modern interface with support for multiple themes (Dracula, VS Code Dark, Light Mode, etc.).
- **🐞 Step Debugger:** Set breakpoints visually by clicking the gutter and step through your code line by line.
- **🔍 Live Variable Inspector:** Watch your variables, lists, and objects update in real-time as your code runs.
- **💻 Integrated Console:** A fully functional terminal for running your programs and installing packages via `pip`.
- **🚀 Ultra Lightweight:** Loads instantly. Uses your system Python to keep the memory footprint extremely low.
- **⚡ Smart Editor:** Syntax highlighting, auto-indentation, and helpful code completion out of the box.

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/khushi03-bot/nova-ide.git
   cd nova-ide
   ```

2. **Install dependencies:**
   Nova IDE only requires PyQt6 to run.
   ```bash
   pip install PyQt6
   ```

3. **Launch the IDE:**
   ```bash
   python main.py
   ```

## 🛠️ Built With

- **Python 3** - Core logic and execution engine
- **PyQt6** - Graphical User Interface (GUI)
- **SQLite3** - Local database for saving preferences and themes
